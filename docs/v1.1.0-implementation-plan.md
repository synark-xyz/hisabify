## Feature 3: AI Voice + OCR (Claude API)

### Changes Made

**`supabase/functions/parse-transaction/index.ts`** (new)
- Deno Edge Function that accepts `{ mode: 'voice' | 'receipt', text, user_currency? }`
- Validates JWT via `supabase.auth.getUser()`
- Fetches user's categories from Supabase for AI context
- Calls `claude-haiku-4-5-20251001` with mode-specific prompts
- Returns `{ merchant, amount, currency, category, date, notes, confidence }`
- Strips markdown fences from Claude response before JSON parse

**`src/components/VoiceInputFlow.tsx`**
- Added `useCurrency` and `supabase` imports
- `parsed` is now state (not derived from transcript)
- After `listen()` resolves, calls `parse-transaction` Edge Function with `mode: 'voice'`
- Shows "Analyzing with AI…" spinner while AI runs
- Falls back to `parseCommand()` regex on Edge Function failure
- Shows confidence badge (medium/low) when AI confidence is not high
- Buttons disabled during AI loading

**`src/components/ReceiptUpload.tsx`**
- Added `useCurrency` and `supabase` imports
- Added `scanLabel` state for dynamic status text ("Scanning Receipt..." / "Extracting with AI...")
- After Tesseract OCR, calls `parse-transaction` Edge Function with `mode: 'receipt'`
- On AI success: calls `onScanComplete` with AI-structured data
- On AI failure: falls back to existing `processReceiptText()` heuristic

### Required Setup (manual)
- Add `ANTHROPIC_API_KEY` to Supabase Edge Function secrets:
  - Supabase Dashboard → Project Settings → Edge Functions → Secrets
- Deploy the new function: `supabase functions deploy parse-transaction`
